jQuery plugin

@passcore/jquery adds $.fn.password() to a jQuery instance. Each card below is a setup of the plugin, with the code that runs it. The language switcher above changes the texts of the translations card.

Default

The meter stays hidden until the input gets focus, then slides in. It slides out again when the input loses focus while empty.

$('#default-password').password()

Always visible

With animate: false the meter is shown from the start, and showPercent adds the number.

$('#always-password').password({ animate: false, showPercent: true })

Linked to a field

With userInputs the password can't contain the username. The field is read on every keystroke.

$('#linked-password').password({ userInputs: ['#username'], showPercent: true })

Translations

The bundled es and ca files are passed as translations, with locale for the plural forms. Switch the language in the header.

import es from '@passcore/jquery/locales/es.json'

$('#translations-password').password({ translations: es, locale: 'es', showPercent: true })

Events

The password.score event gives the percent on every keystroke. Here it enables the button above 75%.

Score: 0%

$('#events-password')
  .password({ animate: false })
  .on('password.score', (event, percent) => {
    $('#send').prop('disabled', percent <= 75)
  })

Input group

The meter is appended to the closest .form-group instead of the closest div, so it goes below the whole input group.

$('#group-password').password({ animate: false, closestSelector: '.form-group' })

Theming

The colours, track and height are CSS custom properties: --pass-color-very-weak to --pass-color-strong, --pass-track and --pass-height. The controls set them on the preview below, and only there, so the other demos keep their look.

  • Very weak
  • Weak
  • Fair
  • Good
  • Strong
Custom properties 
.theme {
  --pass-height: 6px;
  --pass-track: #e5e7eb;
  --pass-color-weak: #c2410c;
  --pass-color-strong: #15803d;
}
